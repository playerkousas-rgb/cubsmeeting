# 活動／技能圖片：依內容混用 SVG 與 AVIF

## 現行規則（2026-09-15）

**格式不是畫風。把粗糙 SVG 轉成 AVIF，不等於變好看。**

| 類別 | 現況 | 用法 |
|---|---:|---|
| 幾何、方向、標記與流程 | 28 張 SVG | 直接渲染向量，放大／打印保持清楚；繼承網頁字型 |
| 新繪生活情境 | 40 張 AVIF 插畫 | 合作、生活、求助及準備情境；短提示保留 HTML |
| 尚未重評的舊圖 | 5 張 AVIF | 暫保留，不冒稱已完成美化；人物／動作圖須逐張檢查 |

最新覆蓋：**73節專屬配圖＋8節參考圖＋0節純文字卡＝81節**。仍有5張舊圖待重評；不代表所有圖片已美化、所有正式動作已核清或所有頁面都有插畫。

SVG 名單：compass、map-legend、eight-dir、bins、bridge、tracking、three-cols、stations、weather、day-plan、community-map、frame-test、route-plan、needs-first、model-review、bridge-predict、tracking-record、compass-practice、weather-backup、next-goal、progress-story、summer-plan、good-deed-plan、requirements-check、travel-explain、command-compare、origin-timeline、five-sections。

人物、表情、真實外觀適合另外繪製插畫或使用有來源的照片，再壓成 AVIF。繩結、手勢、急救可使用合適圖解，但**準確性優先**；不是只生成一張漂亮圖片就算完成。正式制服／徽章不憑想像補畫。

選擇由 `SkillArt.media(id)` 統一管理，畫面、縮圖、放大、投影與列印共用。SVG 每次渲染使用獨立 marker ID，避免同頁圖卡互相引用；向量原稿在已快取的 `js/skill-art.js`，不再另載重複點陣圖。

## 舊圖維護與重繪

`SkillArt.art` 保留可編輯 SVG 原稿。`SkillArt.vectors` 列出適合直接用向量的圖；`SkillArt.illustrations` 列出另行製作的插畫與 HTML 提示。

`tools/render-skill-art.mjs` **只匯出 legacy-diagram 類別**，不能覆寫新插畫，也不會把已選 SVG 的圖又轉為 AVIF。舊版 AVIF 匯出保留作對照及版本相容，但不再預快取被替換的版本；已知畫錯的 `tracking.avif` 除外，已移除。

```sh
# 維護用依賴，APP 本身沒有 build step
npm install --no-save --package-lock=false sharp @fontsource/noto-sans-tc
npx playwright install chromium
# 另一終端啟動靜態伺服器
python3 -m http.server 8090 --bind 0.0.0.0
# 匯出仍採點陣圖的原稿；可設 ART_IDS=overhand
node tools/render-skill-art.mjs
```

工具支援 `BASE_URL`、`CHROMIUM_EXECUTABLE`、`CHROMIUM_ARGS`。Noto Sans TC 僅用於舊圖匯出，依 SIL Open Font License；不派發字型檔。

新插畫須另外製作、目視檢查並更新 `illustrations`；不要用線稿匯出工具冒充插畫重繪。修改圖片或格式後須更新 SW cache，執行 `npm test` 與 `npm run test:browser:all`，確認手機、缺圖備援、離線、單張 A4 及來源標示。
