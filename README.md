據幼童軍訓練綱要設計，將訓練目標化成即用集會、教材與逐步帶領支援。

## 設計方向

以 [ghmeeting](https://github.com/playerkousas-rgb/ghmeeting) 的操作模式為藍本，為幼童軍重新設計準備流程及現場工具。官方集會套包只在上方提供獨立連結，不限定本APP的年度編排。

- **上方／事前準備**：集會目錄、範本、帶領、官方集會套包、手冊。
- **下方／現場即用**：工作紙、活動、技能、森林故事、快鍵。
- **頂欄**：出席記錄、手冊與設定。
- 選集會 → 印教材 → 執袋 → 設場 → 帶領 → 記出席；完成進度保留於裝置。
- 現場活動卡不改動今場選擇。小隊計分、抽籤、集合訊號及倒數可直接使用。
- 外部PDF／APP新分頁開啟；離線時停用，應用本身可離線使用。

## 啟動

```bash
python3 -m http.server 8090 --bind 0.0.0.0

```

另有內置短講／文字題卡（童軍起源、五支部、徽章分類、新春、旅團身份），可分印題面及答案。旅團資料由領袖自行填寫，缺資料不亂估。c02、c16、c24有一週實踐回顧的日期及整體備忘，記錄頁亦可找回；沒有推送提醒或自動獎章判定。

今輪不增加場數、不擴充森林故事、不補圖。仍未核對的正式儀式、肩章或活動徽章細項不冒稱已完成。驗收路徑與來源見 [docs/field-ready-review.md](docs/field-ready-review.md)。

```bash
npm test                 # 包含新實戰內容、資料儲存與隔離測試
npm run test:practical   # 只驗新實戰層

# 額外真瀏覽器測試（先另開 python3 -m http.server 8090 --bind 0.0.0.0）
npm ci
npx playwright install chromium
npm run test:browser     # BASE_URL 可指定其他網址
```

`js/practical-data.js` 保存逐場帶法、問答及文字卡；`js/practical.js` 負責顯示、獨立列印及本機回顧安排。Playwright只屬開發測試依賴，APP本身仍是無build step的靜態PWA。
