# 🐺 幼童軍團集會助手 Cub Hub

一句話定位：**取代官方《幼童軍團集會套包》**。新領袖淨係用呢個 APP 就帶得完一場集會，唔使再翻官方 PDF。
官方套包畀你「睇」，呢個 APP 畀你「帶」，甚至幫你帶。
由年度計劃到散會嗰刻一條龍：開季規劃 → 執集會 → 當日投影帶領 → 事後追蹤。
判斷標準只有一個：呢場集會，領袖仲使唔使開官方套包？答案係「唔使」。

## 點開

靜態 PWA，冇 build step，掉上任何靜態 hosting（Vercel / Netlify / GitHub Pages）就得：

```bash
cd cub-meeting
npx serve .        # 或 python3 -m http.server 8090
```

手機「加到主畫面」即變全螢幕 APP；service worker 會 cache 齊，離線照帶到。

## 點驗

```bash
npm test            # smoke ＋ ui ＋ audit ＋ runtime，全過先好出街
npm run test:smoke  # 數據：22場時間加總、有圖有口令、打印張數公式、獎章路線
npm run test:ui     # 導覽：上四下四、嚮導七步四要素、外部掣新分頁＋離線變灰、A4打印
npm run test:audit  # 審計：SW cache、圖細張、環保打印、技能覆蓋、PWA manifest
```

## 支部內容（幼童軍 8–11 歲，唔係小草蜢）

- 獎章路線：會員章（入團三個月內，保護兒童必修）→ 幼童軍獎章 → 歷奇章 → 高級歷奇章 → 金紫荊獎章（PT/68）→ 專科章
- 傳統：小隊制（每隊六人、隊長＋副隊長）、大聲呼叫 Grand Howl、Akela＋叢林故事、誓詞規律、旅團會操禮儀
- 技能（8–11歲難度）：結繩、急救、方向、露營、社區服務、環保、STEM、簡易野外煮食
- 每個環節有：圖解（內聯SVG，離線睇到）＋ 照讀一句口令 ＋ 節奏 ＋ 安全提示

## 導覽規則

- 上面一條入口列 4 粒（新手快速入口），下面一條工具箱 4 粒（熟手直接跳），兩條都係入口，冇標一二三四。
- 真正 step by step 由「揀咗一場集會」先開始：畫面底部（貼底部列之上）一條窄嚮導條，一次只顯示一步，每步一句「做咩」＋一句「點解」＋一粒動作掣。
- 做完自動跳下一步（印咗→自動，剔齊執袋→自動，設好場→自動，帶完→自動，記咗出席→自動），冇「下一步」掣要你撳。
- 可以收埋，可以完全退出（退咗唔再彈）；換第二場自動重頭計。預設唔出，只喺揀集會頁一張邀請卡：「第一次帶集會？我帶你由頭做到尾」。

## 環保打印

預設只印三樣：小朋友即用紙、貼地標記、領袖一頁流程；其餘喺 APP 睇。
未填名單預設印 1 份。一撳印齊＝教案 1＋分隔頁 1＋圖紙 N，一疊過，A4，打印自動隱藏兩條導覽列＋嚮導條。
