# 教材文字寫法

用戶最新要求（2026-09-11）：內容才是重點；解說要簡單、不要太多字、口語化。圖像稍後補，森林故事維持暫停。

## 寫法

- 領袖照讀的話用自然香港口語；一句講一件事。
- 步驟直接說做甚麼，先講眼前要做的一步，不堆背景或術語。
- 每段以短句為主；步驟通常三步，真的需要才加，不為縮字漏掉必要程序。
- 成員題目短而具體；答案先給一句重點，需要才補一句理由。
- 主畫面先放「點玩／點講／小心甚麼」。來源、版本及詳細補充另放核對區；關鍵安全及未核程序的界線仍須看得到。
- 正式誓詞、規律及已核實口令保留原文；口語解說與正式口令分清楚，不自行改寫。
- 不用長篇「本活動旨在……」，不反覆說明同一件事，不以新增功能代替內容收尾。

## 例子

較長：成員依序觀察指定物品，並透過互相交流說明其用途。

改為：一人揀一件，講下點用，再到下一位。

較長：參與者應在無法辨認下一個路線標記時，尋求負責成人協助。

改為：搵唔到下一個符號？停喺安全位，叫領袖幫手。

## 檢查

寫完問自己：領袖能否直接讀出來？小朋友是否聽一次就知道要做甚麼？有沒有漏掉安全或正式要求？

本文件是後續修改準則，不代表現有所有教案已完成短句改寫。
