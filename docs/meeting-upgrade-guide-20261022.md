# 集會統一改善指南（2026-10-22）

> 用途：把現時 27 場入面已經做好的做法，變成一套可以**逐場照抄**的準則，方便你統一替其餘集會（或日後新增場次）改。
> 配套工具：`node tools/meeting-audit.mjs`（列出邊一場差咩）、`npm test`（22 組，全部要 PASS）。
> 原則：只改「教法同寫法」，**唔改官方原文、唔自創徽章、唔把練習講成已通過考核**。

---

## 一、改邊幾個檔案（按需要才開）

| 檔案 | 裏面係咩 | 幾時要改 |
|---|---|---|
| `js/data.js` | `lesson()` 建場，`activity()` 建每一節 | 改場名、目標、步驟、對白、安全句、物資、設場、家長通知 |
| `js/plain-content.js` | 每場中間各節的「口語版」步驟（小朋友聽得明） | 上面改完之後，同步改口語版 |
| `js/practical-data.js` | `FIELD{}`：每場 7 個實戰情境＋問答＋來源說明 | 補「實戰帶領包」 |
| `js/worksheet-guides.js` | 領袖版工作紙答案 | 工作紙題目改過就要跟 |
| `js/skill-art.js` | 每節的圖解（自繪 SVG） | 想加圖先做，冇圖不影響出頁 |
| `js/material-desk.js` | 物資套裝清單 | 物資清單改過才要跟 |
| `sw.js` | 預快取清單（`ASSETS`／`EXTRA`）＋`CACHE` 版號 | **新增／刪除檔案**，或改完想舊用戶即刻換新（升 `CACHE` 版號） |

> 只改內文（`data.js` 等）**不必**動 `sw.js` 清單；但想用戶即刻見到新版，請升 `CACHE` 版號（`cubhub-v41-…` → `v42`）。

## 二、每場骨架（現行統一做法）

```
第 1 節  集合、點名與今日約定        5 分鐘   ← activity() 內建，通常唔改文字，只改細節
第 2 節  主活動 A                   15 分鐘
第 3 節  主活動 B                   15 分鐘
第 4 節  主活動 C（或深化／分享）    15 分鐘
第 5 節  回顧、收拾與交接           10 分鐘   ← activity() 內建
                             合計：60 分鐘
```

- 節數 **5 節**最順；如要 4 或 6 節，`m.mins` 一定要等於逐節加總（audit 會查）。
- 第 2–4 節每節都要有：3 步做法、一句對白、一句安全提醒、觀察重點、節奏、物資。
- 三節要有節奏變化：**動手 → 動手／討論 → 分享或應用**，唔好三節都係講。

## 三、逐欄位標準（照這個寫就統一）

| 欄位 | 要求 | 好例子 | 唔好咁寫 |
|---|---|---|---|
| `n` 場名 | ≤ 14 字，一眼睇到做乜 | `小隊成立：合作唔靠嗌大聲` | `有關合作精神之探討` |
| `goal` 目標 | 一句、可觀察 | `體驗輪流、互助及處理分歧。` | `培養良好品格` |
| `evidence` 觀察 | 寫「領袖見到咩就當做到」 | `記下每人一次讚賞、一次鼓勵` | `表現良好` |
| `gap` 未涵蓋 | **必寫**，防誤認考完 | `體驗章考驗於完成會員章後開始；迎新遊戲本身不自動計作考驗。` | 留空 |
| `refs` 出處 | 只寫官方章節／編號 | `['會員章 h','1.4.1']` | 自創編號 |
| `adapt.easy` | 一句，點樣減難度 | `用手勢選角色，兩人先練輪流。` | `按能力調整` |
| `adapt.hard` | 一句，點樣加深 | `由隊員協商規則並解釋如何照顧較慢的同伴。` | 加多十倍份量 |
| `segs[].steps` | **3 步**：示範 → 實作 → 分享／檢查；每步 ≤ 40 字 | `領袖示範一次，再請兩人做。` | 一句寫 100 字 |
| `segs[].script` | 一句，20–30 字，用「」 | `「未輪到都可以幫手諗，但唔代人做。」` | 長篇訓話 |
| `segs[].safety` | 一句，講「唔做乜」 | `不推撞、不拉人站位。` | `注意安全` |
| `segs[].watch` | 觀察到咩就當達標 | `能輪流、鼓勵及接受重試。` | `表現理想` |
| `segs[].rhythm` | 分鐘分配 | `示範3分鐘 → 實作9分鐘 → 分享3分鐘` | 留空（會用預設） |
| `bag` 物資 | ≥ 3 項，寫實物名 | `['紙杯','大畫紙','彩色筆']` | `文具` |
| `venue` 設場 | 一句，講空間要求 | `每隊一張枱，留出走道` | 留空 |
| `notice` 家長通知 | 必含集合／接送／取消／支援 | 見 `data.js` 內建結尾句（已自動加） | 只寫「準時」 |
| `worksheet.title` | 場名＋用途 | `小隊成立：合作唔靠嗌大聲｜合作記錄` | `工作紙` |
| `worksheet.prompts` | 3 題，成員寫／畫／口述都得 | `畫我哋嘅小架，寫我負責咩。` | 直接問答案 |
| 實戰包 `practical` | 7 個情境（`opening, distribute, confused, quiet, few, missing, short`）＋`qa` ≥ 2＋`sourceNote` | 見 `js/practical-data.js` 的 `FIELD.c01` | 只寫 `quiet` |
| 口語版 `plain-content` | 中間各節各 3 句，句子 ≤ 25 字，全部廣東話 | 見 `js/plain-content.js` `c01` | 照抄書面語原文 |

### 字數上限（實測出來的界線）
- 一步 ≤ **40 字**；一句對白 ≤ **30 字**；一句安全 ≤ **30 字**。
- 一節 3 步加起上嚟 ≤ **110 字**，超出就會令「投影帶領」一屏睇唔完。

## 四、四條鐵律（改任何一場都不可以破）

1. **唔自創儀式**：團呼、敬禮、展旗、宣誓只可由熟悉正式程序的領袖按綱要第五章教；活動裏只可以「練習集合約定」，並寫明不算考核。
2. **唔公開私隱**：健康、家庭、聯絡資料只由領袖私下核對；工作紙唔可以要求地址、門牌、樓層、相片。
3. **唔把練習講成已考獲**：每場 `gap` 必須寫「本場不…／須另行觀察」。
4. **唔虛構**：未核實的徽章圖樣、尺寸、車縫、肩章職級，一律寫「待核對」並連去官方，不畫不估。

## 六、批量改的建議次序（每場 15–20 分鐘）

1. 開 `node tools/meeting-audit.mjs --all`，睇邊場差咩。
2. 改 `js/data.js` 該場的 `lesson(...)`：先 `goal`／`evidence`／`gap`，再逐節 `activity(...)`。
3. 同步改 `js/plain-content.js` 中間各節口語（第 1 與最後一節共用文字，唔使寫）。
4. 補 `js/practical-data.js` 的 `FIELD.<tid>`（7 個情境＋2 條問答＋`sourceNote`）。
5. 改過工作紙題目 → 跟 `js/worksheet-guides.js` 的領袖答案。
6. 跑 `npm test`；再跑 `node tools/meeting-audit.mjs --strict`，兩樣都應該乾淨。

### 安全換字做法（避免靜靜改錯）
`data.js` 一行很長，用 Python 換字**一定要加 assert**，唔好靠肉眼：

```python
a = "輪流起杯塔"                 # 一定只出現一次
assert s.count(a) == 1
s = s.replace(a, "輪流築杯塔", 1)
```
改完用 `node -e "new Function(require('fs').readFileSync('js/data.js','utf8'))"` 確認語法。

## 九、唔可以改嘅嘢（改之前停一停）

- `#official` 頁（`App.vOfficial`）：只可以連去官方，唔可以加卡、加掣、加內容。
- 官方 PDF／Google Drive 連結：固定不變（集會套包、《訓練綱要》2026 第十版）。
- 誓詞、規律、團呼口號、急救／求醫條件：**原文照登**，唔可以為簡潔刪句。
- 成員（兒童）工作紙：**不可**出現領袖答案、不可有相片收集要求。
- 官方圖片：不可自繪、不可 AI 生成；自繪圖一定要標「示意」並收埋喺 `<details class="map-self">`。
