## 本輪完成範圍

不增加場數、不擴充森林故事、不製作圖片。現有27場中，森林故事兩場維持原內容，其餘25場新增實戰帶領包。

每場具備：

1. 開場照讀的一句話。
2. 分組及派物次序。
3. 成員聽不明白時的下一個示範或提示。
4. 不投入、不願公開回答時的替代參與方式。
5. 少人玩法。
6. 缺物資的安全後備，明確說出不能因此計作完成的項目。
7. 30分鐘縮短建議（3分鐘開始、20分鐘重點、7分鐘回顧收拾交接），不改原有集會時間或完成記錄。需要額外交通、支援、交接的時間不硬塞進30分鐘。
8. 兩條有參考答案的檢查問題，共50條。先顯示問題，再由領袖揭答案；轉題自動收起答案。

以上是自行編寫的教法，不是新增的獎章門檻或正式人手比例。正式要求、實際操作與一週實踐仍須分清。

## 可直接用的材料

- 童軍起源短講與六張時間／背景卡。
- 五支部名稱卡。
- 會員章、四個進度性獎章、核心與興趣範疇及活動徽章例子的分類卡。
- 新春習俗短講及三張情境卡（自行選用的節慶例子，不聲稱為唯一由來）。
- 旅團四資料卡：旅號、區、地域、主辦機構。由領袖填真實資料，保存在本機；未填時明示待核，不生成假的旅團名稱。
- 題面與領袖答案可分開列印；題面不洩露答案。每六張文字卡一頁，最多六張。
- 每場另可印一頁領袖實戰摘要，並保留原來文字工作紙列印功能。開獨立題卡不切換今場、不標記準備或獲章完成。

## 一週實踐跟進

c02誓詞善事、c16減廢行動、c24生活規律／三次小幫手有獨立回顧卡：家庭任務、下次要問的三句、觀察重點、回顧日期及整體備忘。

入口在準備頁、詳細資料頁及「記錄」頁。資訊只存本機，沒有推送提醒、跨裝置／跨APP同步或自動獎章簽核。「已回顧」只表示領袖已做回顧，並不把所有團員標達標。日期作有效日期驗證，輸入安全轉義；儲存失敗時不關閉表單或顯示成功。

## 建議檢查路徑

### 1. c14童軍起源

集會目錄 → c14 → 開場照讀 → 童軍起源時間卡 → 印題面／答案 → 問題卡 → 先回答再揭答案。

檢查：領袖是否還要自己另外寫短講？孩子未識字時是否帶得下去？縮短版是否清楚講明刪去了甚麼？

### 2. c01小隊合作

準備c01 → 旅團身份卡 → 填四個真實資料 → 關閉／重開 → 看內容是否保留。缺紙杯時開實戰卡，看替代玩法。

### 3. c24生活小幫手

準備c24 → 家庭任務／回顧 → 選日期及寫備忘 → 儲存 → 重新整理 → 在記錄頁找回。不要因設定日期就把一週任務視作完成。

### 4. c06／c08技能安全

活動庫單獨開一節 → 問題卡或少人／缺物資方案。確認只作口述時沒有自動宣稱繩結或急救操作完成，且原本今場選擇不變。
