## 二、程式員角度：實際修正

1. **場次數硬編碼**：`App.vMeetList()` 寫死「22場」，實際 27 場 → 改為 `DATA.meetings.length`。
2. **WhatsApp 通知連結失效**：原本 `href="https://wa.me/?text="` 空內容，未按「複製」直接開會是空白 → 改為載入時已帶入通知全文。
3. **抽籤名單設定不持久**：離開快鍵頁再回來，勾選被重設 → 以 `cub_pickuse` 記住，並保留測試所要求的 DOM 勾選行為。
4. **帶領中斷無法續帶**：重載後由第一段開始 → 以 `cub_leadidx_<tid>` 記住目前段，完成畫面加「由頭再帶」。
5. **搜尋森林故事只去列表**：搜到故事但不會開該集 → 結果直接 `Jungle.open(i)`。
6. **搜尋在彈窗關閉後仍輸入**：`searchRun` 讀不到 `#searchbox` 會拋錯 → 加空值檢查。
7. **模態框無背景隔離**：Tab 可走到背後按鈕 → 開框時對 `#app`／`#leadroot` 設 `inert`，關閉時移除並把焦點還原。
8. **上一頁不關彈窗**：hash 改變但模態框仍蓋住新頁 → `App.route()` 開始時關閉現有模態框。
9. **音效每次新建 AudioContext**：長集會反覆響哨會耗資源 → 重用單一 context 並 resume。
10. **`curTid` 可能留下無效場次**：舊記錄指向已刪場次時目錄沒有高亮 → 初始化時校正回 `c01`。
11. **`App.clearLocal` 未防儲存例外**：私密模式可能拋錯 → try/catch，只清 `cub_` 開頭記錄。
12. **手冊 `sub=` 無效值**：會顯示空白提示 → 自動回落「誓詞·規律」。
13. **NaN 防護**：制服配對、儀式卡、實戰問題卡的上一／下一題加 `Number.isFinite` 檢查。
14. **內部開發字句外洩**：官方套包頁、手工頁、安全頁出現「跟 ghmeeting 同款」、「內部定位：武器庫」等 → 只改本APP自己嘅說明文字，官方PDF、連結及內容一律不動。
15. **手工頁死掣**：四張卡只彈 toast「即開即用」 → 改為連結素材庫。

## 六、仍待處理／風險

- 2026 官方位置圖已內置並逐項對回綱要文字；初級（銅選）／中級（銀選）／高級（金選）同隊長／副隊長章位置，圖上已有標示。仍未有的係**章形、尺寸、條數嘅實物樣本**及車縫尺寸，繼續以實物核對，不自行畫徽章。
- 摺旗／繫旗、隊長就職、晉團、肩章圖樣仍待官方示範；現有卡已明示未完成。
- 列印 CSS 仍有 8 個 `@media print` 區塊，未曾合併；今次只改 token 與元件，未重構，以免影響既有 A4 分頁。
- 未能在真機 iOS／Android 及真 Chromium 截圖驗證；`tests/browser*` 需另行安裝瀏覽器。jsdom 只覆蓋邏輯與 DOM，不覆蓋實際排版。
- `/_vercel/insights/script.js` 在離線或非 Vercel 主機會載入失敗（不影響功能）；如要完全離線及避免第三方請求，可考慮移除。
