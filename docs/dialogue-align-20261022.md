# 對齊用對話紀錄（2026-10-22・幼童軍集會 APP）

> 用途：把今次一整輪「你講一句 → 我點做 → 實測數字」原樣記落嚟，其他 MEETING APP（童軍／深資童軍／樂行童軍／旅團通用）可以照住同一套標準改，唔使再逐樣問。
> 讀法：🟦 = 你講；🟩 = 我做的；⬜ = 實測／結論；⚠️ = 唔可以改嘅嘢。

## 第 1 回合｜制服

🟦「制服要 UPDATE 新版。」
🟩 以 2026 第十版《訓練綱要》第一章（十一）＋ P022/26 為準：4 個核心範疇章在左袖、隊長章／副隊長章在左胸袋會員章下方、6 色活動章；舊 2025 圖只留作對照，並寫明「未顯示新制」。
⬜ 官方圖只用官方插畫，**唔自繪、唔 AI 生成**；自繪示意圖一律收埋喺 `<details class="map-self">` 並標「示意」。
**其他 MEETING 照做**：制服頁只可以有「官方圖」＋「實物核對」＋「來源連結」三段；任何自繪圖都要收埋同標示意。

## 第 2 回合｜字要精簡

🟦「字要再簡潔 1 點。」
🟩 以「可見字數」做預算，逐頁量度：集會目錄 1,037 字、手冊 394、森林故事 727、集會詳情 783、活動 911、制服 650、典禮 603。
⬜ 做法＝把次要內容收成 `<details>`，**唔係刪官方原文**。誓詞、規律、團呼口令、急救／求醫條件一句都唔可以因為「精簡」而消失。
**其他 MEETING 照做**：先量度，再收納；列印前要自動打開所有 `details`，印完還原（本 APP 實測 15 個收埋 → 印前 0 → 印後 15）。

## 第 3 回合｜三種身份找 BUG

🟦「用程序員／新領袖／資深領袖／網頁設計師角度查找 BUG 及改善整個 APP。」
🟩 修好：7 頁冇 `h1`、標題跳級、外連被當「目前頁」、導覽掣矮過 44px、活動頁主標題排得太後、`js/jungle.js` 自己再寫一次路由（令森林故事冇 `aria-current`）、`#meet` 無 `tid` 時的空白死頁。

**其他 MEETING 照做**：路由只准一個檔案負責（連 `aria-current`）；每個 view 只出一個 `h1`；子頁（例如投影帶領、試卷庫）唔可以用 `h2` 做頁名。

## 第 5 回合｜五項改善（評分建議落地）

🟦「按你建議去改善。」
🟩 ①集會目錄四粒篩選（全部／未做／已完成／本月）＋「繼續上次」卡；②首頁續帶卡顯示「上次帶到第 N/5 段」；③預快取由 **141 檔 5.70 MB → 33 檔 1.00 MB**，其餘 106 檔 4.70 MB 閒置時背景補；④活動頁由 164 個掣 → 首批 12 張卡＋「睇多啲」；⑤手冊 8 個教材分頁只 render 第一個（8,953 bytes，開齊 12,299）。

## 第 9 回合｜意見回報

🟦「這 APP 有回報意見系統嗎？沒有就去 ADMIN 那看看如何加進來。」
🟩 原本**冇**。查 `scout-admin`（Scout Admin 統一回報 v1）後照官方做法接入，一行：

```html
<script src="https://scout-admin-blue.vercel.app/widget.js" data-app="幼童軍集會" defer></script>
```

另加離線退路：手冊「📮 意見回報」卡（複製文字／網頁版表單），並在 CSS 把浮動掣升上底部導覽（≥44px）。
⬜ **關鍵陷阱**：`data-app` 唔可以用「幼童軍」——Scout Admin 會把它歸入**專章系統**（因為 `cubsbadge` 已用這個名）；用「幼童軍集會」就會以 `🔹 幼童軍集會` 原樣顯示，照樣分流唔會漏單。
**其他 MEETING 照做**：`童軍集會`／`深資童軍集會`／`樂行童軍集會`／`旅團集會`；詳見 `docs/feedback-system.md`。

# 其他 MEETING 對齊清單（可直接照勾）

## A. 內容層
- [ ] 制服以 2026 第十版＋P022/26 為準；舊圖標明「未顯示新制」
- [ ] 每場 5 節 60 分鐘；`mins` = 逐節加總
- [ ] 每場必寫「本場不涵蓋／須另行觀察」（`gap`）
- [ ] 官方原文（誓詞、規律、口令、急救條件）一句不漏
- [ ] 未核實的章形／尺寸／肩章寫「待核對」，唔畫唔估

## B. 介面層
- [ ] 每頁 1 個 `h1`、0 標題跳級、0 重複 id
- [ ] 次要區塊收 `details`；列印前自動開、印完還原
- [ ] 大量卡片分批（首批 12＋「睇多啲」）
- [ ] 手冊教材分頁延遲 render
- [ ] 外連一律 `target="_blank" rel="noopener"`，唔加 `aria-current`
- [ ] 路由只由一個檔案負責

## C. 系統層
- [ ] 預快取 ≤ 約 1–2 MB，大圖改背景補（`CACHE_EXTRA`）
- [ ] 改完升 `CACHE` 版號
- [ ] 意見回報：官方 widget 一行＋`data-app`（**唔用單一支部名**）＋離線後備
- [ ] `npm test` 全 PASS；新功能要有棘輪測試

## D. 文件層
- [ ] 評分文件寫「每身份 ≥90」同實測數字
- [ ] 改善指南（逐欄位標準）＋檢查工具
- [ ] 來源／限制句在畫面上睇得到，唔止寫在文件

## ⚠️ 共通「唔可以改」
1. `#official` 官方套包頁：只可以連去官方，唔可以加卡、加掣、加內容。
2. 官方 PDF／Drive 連結與原文：唔複製、唔改寫、唔刪句。
3. 成員（兒童）工作紙：唔可以有領袖答案、唔可以收集個人資料／相片。
4. 官方圖片：唔自繪、唔 AI 生成；自繪圖一定標「示意」並收埋。
5. 練習唔可以講成「已通過考核」。
